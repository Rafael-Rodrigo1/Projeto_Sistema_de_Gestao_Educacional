# Projeto_Sistema_de_Gestao_Educacional
# 📘 Sistema de Gestão Acadêmica – Java

Este projeto é um sistema simples de gestão acadêmica desenvolvido em **Java**, aplicando conceitos de **Programação Orientada a Objetos (POO)** e uma arquitetura organizada em camadas. Ele permite cadastrar e gerenciar **alunos, professores, cursos e turmas**, além de registrar avaliações.

---

## 🚀 Funcionalidades

- Cadastro de **Alunos**, **Professores** e **Cursos**
- Criação de **Turmas**
- Adicionar alunos às turmas
- Registrar avaliações
- Gerar relatórios gerais

---

## 🏛 Arquitetura do Projeto

- **model/** – Classes principais (Aluno, Professor, Curso, Turma, Avaliação)
- **repository/** – Armazena os dados em memória
- **service/** – Regras de negócio (turmas, avaliações etc.)
- **UI/** – Menu interativo via console
- **Main.java** – Ponto de entrada do sistema
